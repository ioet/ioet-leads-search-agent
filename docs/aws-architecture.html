Leads search architecture

AWS, LittleHorse, and SaaS
Compute Storage AI Network

LittleHorse Cloud runs leads-search-workflow and enrich-and-publish-lead. ECS task workers in a VPC poll LittleHorse and call seven Lambda functions. skills calls BambooHR, hubspot calls HubSpot, jobs reads LinkedIn and company websites, apollo calls Apollo, notify calls Slack, icp reads the ICP object in S3, and agent calls Amazon Bedrock.
